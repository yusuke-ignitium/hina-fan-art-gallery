このギャラリーへの作品追加は GitHub の「プルリクエスト」という仕組みで受け付けています。 送ってもらった作品は管理人が確認し、OK なら掲載されます。 はじめてでも下の手順どおりに進めば 10 分ほどで完了します。

STEP 1 — GITHUB アカウントを作る

すでにアカウントを持っている場合は STEP 2 へ。

  1. github.com/signup を開く
  2. メールアドレス、パスワード、ユーザー名を入力する
    ※ ユーザー名は公開されます。掲載時に作品のクレジット「by ユーザー名」として表示されるので、見られてもよい名前にしてください
  3. メールに届いた確認コードを入力すれば完了

STEP 2 — 作品を投稿する

  1. 下のボタンからギャラリーのリポジトリ(作品置き場)を開く
    OPEN REPOSITORY
  2. 右上の Fork ボタンを押し、次の画面で Create fork を押す
    ※ 自分専用のコピーが作られます。元のギャラリーには影響しません
  3. コピーされたページで images フォルダを開く
  4. Add file → Upload files を押して、画像をドラッグ&ドロップ
    ※ ファイル名がそのまま作品タイトルになります。例: night-walk.png →「night walk」(- や _ はスペースとして表示)
  5. Commit changes を押す
  6. ページ上部に戻り Contribute → Open pull request → Create pull request を押す

これで投稿完了です。管理人が内容を確認して取り込むと、ギャラリーに自動で反映されます。

・掲載までは少し時間がかかることがあります
・公序良俗に反する画像、他者の作品の無断転載はお断りします
